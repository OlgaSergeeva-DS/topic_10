# Динамическое программирование и алгоритм Флойда-Уоршелла

Финальное домашнее задание по курсу алгоритмов.

## 📌 1. Задача о рюкзаке (Knapsack Problem)
Реализована классическая задача 0-1 о рюкзаке. Используется двумерная таблица `dp`, где строки — это предметы, а столбцы — доступная вместимость рюкзака. На каждом шаге мы решаем: положить предмет (если он влезает) или пропустить его, выбирая максимальную стоимость.

## 📌 2. Наибольшая общая подпоследовательность (LCS)
Алгоритм находит длину наибольшей общей подпоследовательности для двух строк. Таблица `dp` размером `m x n` заполняется сравнением символов. Если символы совпадают, берется значение по диагонали + 1. Если нет — берется максимум из соседа сверху или слева.

## 📌 3. Количество способов разбить число
Алгоритм динамического программирования для подсчета количества уникальных комбинаций, которыми можно составить число `n` из чисел от 1 до `n`. Одномерный массив `dp` обновляется так: количество способов получить сумму `i` увеличивается на количество способов получить сумму `i - num`.

## 📌 4. Алгоритм Флойда-Уоршелла
Алгоритм для поиска кратчайших путей между всеми парами вершин в графе. Работает за O(V³). На каждом шаге мы проверяем: "А не будет ли путь из вершины `i` в вершину `j` короче, если мы зайдем через вершину `k`?" Если да — обновляем расстояние.
